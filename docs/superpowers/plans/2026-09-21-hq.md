# hq Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `hq`, an Elixir daemon that lets Claude Code sessions running in Herdr panes send messages to each other, delivered by typing into the target session's visible I/O when it goes idle.

**Architecture:** One `Hq.Session` GenServer per agent, each owning a dedicated long-lived socket carrying that pane's Herdr event subscription, plus a durable mailbox. Herdr's socket answers exactly one request per connection and serves only events once subscribed, so per-agent connections are required by the protocol, not a stylistic choice. A control socket accepts CLI verbs; an escript autostarts the daemon.

**Tech Stack:** Elixir 1.20.4 / OTP, zero runtime dependencies (built-in `JSON`, `:gen_tcp` unix domain sockets, ExUnit). Talks to Herdr 0.9.1, protocol 22.

**Spec:** `docs/superpowers/specs/2026-09-21-hq-design.md`

## Global Constraints

- **Elixir ≥ 1.18 required** (built-in `JSON` module); target 1.20.4. **Zero runtime dependencies** — do not add Jason, Poison, or any HTTP library.
- **Herdr request `id` MUST be a string.** An integer id returns `invalid_request`.
- **One request per connection.** A second request written to the same Herdr socket is never answered. Every `Hq.Herdr.call/2` opens and closes its own connection.
- **`events.subscribe` connections serve only events.** Never issue a request on a subscribed socket.
- **Subscription types are dotted; the pushed `event` kind is NOT consistently snake_case — Herdr is inconsistent per event type.** Subscribe to `"pane.agent_status_changed"` (dotted). What comes back in the pushed envelope's `event` field varies by subscription type; measured against the live server (0.9.1, protocol 22):

  | subscription type | pushed `event` value |
  |---|---|
  | `pane.closed` | `pane_closed` (snake_case) |
  | `pane.exited` | (not observed) |
  | `pane.agent_status_changed` | `pane.agent_status_changed` (dotted, unchanged) |

  `Hq.Herdr.Events` normalizes the pushed kind on receipt (`.` → `_`) before forwarding it to its owner as `{:hq_event, kind, data}`, so every consumer matches one canonical snake_case spelling regardless of which form Herdr used for that event. Do not rely on a pushed kind matching its subscription type's casing, and do not add a second match clause per consumer for this — normalize at the boundary instead.
- **Per-pane subscriptions require `pane_id`**: `pane.agent_status_changed`, `pane.output_matched`, `pane.scroll_changed`. All others are global.
- **Agent names must match `[a-z][a-z0-9_-]{0,31}`** and be unique among live agents. An hq name IS the Herdr agent name — no mapping table.
- **Deliver only when status is `idle` or `done`.** Hold on `working`, `blocked`, and `unknown`. `unknown` means Herdr could not classify the pane; it is not proof of readiness.
- **`agent.prompt` params are `target` and `text`** (plus optional `wait`). Never pass `wait` — Sessions track state through events.
- **`agent.get` returns `.result.agent`; `agent.list` returns `.result.agents`.** The `name` key is **absent** on unnamed agents — never assume it is present.
- All runtime state lives under `~/.hq/`, overridable via `Application.get_env(:hq, :root)` for tests.
- Herdr socket path is `~/.config/herdr/herdr.sock`, overridable via `Application.get_env(:hq, :herdr_socket)`.

# test/support/fake_herdr.ex
defmodule FakeHerdr do
  @moduledoc """
  A real unix-socket server speaking Herdr's wire protocol.

  Mirrors the two protocol properties that constrain the client: exactly one
  request is answered per connection, and a connection that subscribes to
  events thereafter carries only events. A client that violates either will
  hang here, which is the point.
  """
  use GenServer

  defstruct [:path, :listen, calls: [], replies: %{}, subscribers: []]

  # -- API ------------------------------------------------------------------

  def start_link(opts \\ []), do: GenServer.start_link(__MODULE__, opts)

  def path(pid), do: GenServer.call(pid, :path)
  def stub(pid, method, result), do: GenServer.call(pid, {:stub, method, {:result, result}})
  def stub_error(pid, method, error), do: GenServer.call(pid, {:stub, method, {:error, error}})
  def calls(pid), do: GenServer.call(pid, :calls)
  def subscriber_count(pid), do: GenServer.call(pid, :subscriber_count)
  def push_event(pid, kind, data), do: GenServer.call(pid, {:push_event, kind, data})
  def drop_subscribers(pid), do: GenServer.call(pid, :drop_subscribers)

  # -- Server ---------------------------------------------------------------

  @impl true
  def init(opts) do
    path = Keyword.get_lazy(opts, :path, &tmp_path/0)
    File.mkdir_p!(Path.dirname(path))
    File.rm(path)

    {:ok, listen} =
      :gen_tcp.listen(0, [
        :binary,
        {:ifaddr, {:local, path}},
        active: false,
        packet: :line,
        reuseaddr: true
      ])

    server = self()
    spawn_link(fn -> accept_loop(listen, server) end)

    {:ok, %__MODULE__{path: path, listen: listen}}
  end

  @impl true
  def handle_call(:path, _from, st), do: {:reply, st.path, st}
  def handle_call(:calls, _from, st), do: {:reply, Enum.reverse(st.calls), st}
  def handle_call(:subscriber_count, _from, st), do: {:reply, length(st.subscribers), st}

  def handle_call({:stub, method, reply}, _from, st) do
    {:reply, :ok, %{st | replies: Map.put(st.replies, method, reply)}}
  end

  def handle_call({:push_event, kind, data}, _from, st) do
    line = [JSON.encode!(%{"event" => kind, "data" => data}), ?\n]
    Enum.each(st.subscribers, &:gen_tcp.send(&1, line))
    {:reply, :ok, st}
  end

  def handle_call(:drop_subscribers, _from, st) do
    Enum.each(st.subscribers, &:gen_tcp.close/1)
    {:reply, :ok, %{st | subscribers: []}}
  end

  @impl true
  def handle_cast({:request, req, sock}, st) do
    %{"id" => id, "method" => method} = req
    params = Map.get(req, "params", %{})
    st = %{st | calls: [%{"method" => method, "params" => params} | st.calls]}

    case method do
      "events.subscribe" ->
        send_line(sock, %{"id" => id, "result" => %{"type" => "subscription_started"}})
        {:noreply, %{st | subscribers: [sock | st.subscribers]}}

      _ ->
        resp =
          case Map.get(st.replies, method) do
            {:result, result} -> %{"id" => id, "result" => result}
            {:error, error} -> %{"id" => id, "error" => error}
            nil -> %{"id" => id, "error" => %{"code" => "unstubbed", "message" => method}}
          end

        send_line(sock, resp)
        :gen_tcp.close(sock)
        {:noreply, st}
    end
  end

  @impl true
  def terminate(_reason, st) do
    :gen_tcp.close(st.listen)
    File.rm(st.path)
    :ok
  end

  # -- Internals ------------------------------------------------------------

  defp send_line(sock, map), do: :gen_tcp.send(sock, [JSON.encode!(map), ?\n])

  defp accept_loop(listen, server) do
    case :gen_tcp.accept(listen) do
      {:ok, sock} ->
        pid = spawn(fn -> handle_conn(sock, server) end)
        :ok = :gen_tcp.controlling_process(sock, pid)
        send(pid, :go)
        accept_loop(listen, server)

      {:error, _} ->
        :ok
    end
  end

  defp handle_conn(sock, server) do
    receive do
      :go -> :ok
    after
      1_000 -> :ok
    end

    case :gen_tcp.recv(sock, 0, 5_000) do
      {:ok, line} ->
        # Hand ownership to the server so a subscription outlives this process.
        :ok = :gen_tcp.controlling_process(sock, server)
        GenServer.cast(server, {:request, JSON.decode!(line), sock})

      _ ->
        :gen_tcp.close(sock)
    end
  end

  defp tmp_path do
    rand = Base.encode16(:crypto.strong_rand_bytes(6), case: :lower)
    Path.join(System.tmp_dir!(), "fake-herdr-#{rand}.sock")
  end
end
```

# lib/hq/herdr.ex
defmodule Hq.Herdr do
  @moduledoc """
  Client for the Herdr control socket.

  Herdr answers exactly one request per connection: a second request written to
  the same socket is never answered. Every call therefore opens its own
  connection, which on a unix domain socket costs microseconds and is not worth
  pooling around.
  """

  @default_timeout 30_000

  @spec call(String.t(), map(), keyword()) :: {:ok, map()} | {:error, term()}
  def call(method, params \\ %{}, opts \\ []) do
    timeout = Keyword.get(opts, :timeout, @default_timeout)

    with {:ok, sock} <- connect(timeout),
         :ok <- send_request(sock, method, params),
         {:ok, line} <- :gen_tcp.recv(sock, 0, timeout) do
      :gen_tcp.close(sock)
      decode(line)
    else
      {:error, reason} -> {:error, reason}
    end
  end

  @spec connect(pos_integer()) :: {:ok, :gen_tcp.socket()} | {:error, term()}
  def connect(timeout \\ @default_timeout) do
    :gen_tcp.connect(
      {:local, socket_path()},
      0,
      [:binary, active: false, packet: :line],
      timeout
    )
  end

  @spec send_request(:gen_tcp.socket(), String.t(), map()) :: :ok | {:error, term()}
  def send_request(sock, method, params) do
    # The id must be a string; an integer is rejected as invalid_request.
    payload = JSON.encode!(%{"id" => new_id(), "method" => method, "params" => params})
    :gen_tcp.send(sock, [payload, ?\n])
  end

  @spec socket_path() :: String.t()
  def socket_path do
    Application.get_env(:hq, :herdr_socket) || Path.expand("~/.config/herdr/herdr.sock")
  end

  defp decode(line) do
    case JSON.decode(line) do
      {:ok, %{"result" => result}} -> {:ok, result}
      {:ok, %{"error" => error}} -> {:error, error}
      {:ok, other} -> {:error, {:unexpected_response, other}}
      {:error, reason} -> {:error, {:bad_json, reason}}
    end
  end

  defp new_id, do: Base.encode16(:crypto.strong_rand_bytes(8), case: :lower)
end
```

# lib/hq/herdr/events.ex
defmodule Hq.Herdr.Events do
  @moduledoc """
  One long-lived connection carrying a Herdr event subscription.

  Once `events.subscribe` succeeds, Herdr serves only events on that socket, so
  a subscription cannot share the request connection and each subscription set
  needs a socket of its own. That is why a Session owns one of these rather
  than there being a single shared event process.
  """
  use GenServer
  require Logger

  @backoff_ms [250, 500, 1_000, 2_000, 5_000]

  def start_link(opts), do: GenServer.start_link(__MODULE__, opts)

  @impl true
  def init(opts) do
    state = %{
      owner: Keyword.fetch!(opts, :owner),
      subscriptions: Keyword.fetch!(opts, :subscriptions),
      sock: nil,
      attempt: 0
    }

    {:ok, state, {:continue, :connect}}
  end

  @impl true
  def handle_continue(:connect, state) do
    case subscribe(state.subscriptions) do
      {:ok, sock} ->
        send(state.owner, {:hq_events, :connected})
        {:noreply, %{state | sock: sock, attempt: 0}}

      {:error, reason} ->
        Logger.warning("hq: events.subscribe failed: #{inspect(reason)}")
        Process.send_after(self(), :reconnect, backoff(state.attempt))
        {:noreply, %{state | sock: nil, attempt: state.attempt + 1}}
    end
  end

  @impl true
  def handle_info({:tcp, sock, line}, %{sock: sock} = state) do
    case JSON.decode(line) do
      {:ok, %{"event" => kind, "data" => data}} ->
        send(state.owner, {:hq_event, kind, data})

      _ ->
        :ok
    end

    {:noreply, state}
  end

  def handle_info({:tcp_closed, sock}, %{sock: sock} = state) do
    send(state.owner, {:hq_events, :disconnected})
    Process.send_after(self(), :reconnect, backoff(state.attempt))
    {:noreply, %{state | sock: nil, attempt: state.attempt + 1}}
  end

  def handle_info({:tcp_error, sock, _}, %{sock: sock} = state) do
    handle_info({:tcp_closed, sock}, state)
  end

  def handle_info(:reconnect, state), do: {:noreply, state, {:continue, :connect}}
  def handle_info(_other, state), do: {:noreply, state}

  defp subscribe(subscriptions) do
    with {:ok, sock} <- Hq.Herdr.connect(5_000),
         :ok <- Hq.Herdr.send_request(sock, "events.subscribe", %{"subscriptions" => subscriptions}),
         {:ok, line} <- :gen_tcp.recv(sock, 0, 5_000),
         {:ok, %{"result" => %{"type" => "subscription_started"}}} <- JSON.decode(line) do
      :ok = :inet.setopts(sock, active: true)
      {:ok, sock}
    else
      {:ok, %{"error" => error}} -> {:error, error}
      {:ok, other} -> {:error, {:unexpected_response, other}}
      {:error, reason} -> {:error, reason}
    end
  end

  defp backoff(attempt), do: Enum.at(@backoff_ms, attempt, List.last(@backoff_ms))
end

```elixir
# lib/hq/mailbox.ex
defmodule Hq.Mailbox do
  @moduledoc """
  Durable per-session FIFO queue.

  The file is the queue and memory is the cache. Without this, a daemon restart
  would drop every queued message with no trace — a silent-loss failure mode
  that is much worse than the cost of writing a few lines of JSON.
  """

  defstruct [:name, :path, pending: []]

  @type t :: %__MODULE__{name: String.t(), path: String.t(), pending: [map()]}

  @spec load(String.t()) :: t()
  def load(name) do
    path = path_for(name)

    pending =
      case File.read(path) do
        {:ok, body} ->
          body
          |> String.split("\n", trim: true)
          |> Enum.flat_map(fn line ->
            case JSON.decode(line) do
              {:ok, msg} -> [msg]
              _ -> []
            end
          end)

        {:error, _} ->
          []
      end

    %__MODULE__{name: name, path: path, pending: pending}
  end

  @spec enqueue(t(), String.t(), String.t()) :: t()
  def enqueue(%__MODULE__{} = mb, from, body) do
    msg = %{
      "from" => from,
      "body" => body,
      "at" => DateTime.utc_now() |> DateTime.to_iso8601()
    }

    # Appending keeps FIFO obvious; queues here are a handful of messages at most.
    persist(%{mb | pending: mb.pending ++ [msg]})
  end

  @spec drain(t()) :: {[map()], t()}
  def drain(%__MODULE__{pending: []} = mb), do: {[], mb}

  def drain(%__MODULE__{pending: pending} = mb) do
    {pending, persist(%{mb | pending: []})}
  end

  @spec depth(t()) :: non_neg_integer()
  def depth(%__MODULE__{pending: pending}), do: length(pending)

  @spec path_for(String.t()) :: String.t()
  def path_for(name), do: Path.join([root(), "mailbox", "#{name}.ndjson"])

  @spec root() :: String.t()
  def root, do: Application.get_env(:hq, :root) || Path.expand("~/.hq")

  defp persist(%__MODULE__{path: path, pending: pending} = mb) do
    File.mkdir_p!(Path.dirname(path))
    File.write!(path, Enum.map(pending, &[JSON.encode!(&1), ?\n]))
    mb
  end
end

# lib/hq/envelope.ex
defmodule Hq.Envelope do
  @moduledoc """
  Renders queued messages into the text typed into a session's I/O.

  The `[hq]` prefix is load-bearing: a receiving agent must be able to tell peer
  mail from its own operator's instructions at a glance.
  """

  @spec render([map()]) :: String.t()
  def render([%{"from" => from, "body" => body}]) do
    "[hq] message from #{from}:\n#{body}"
  end

  def render(msgs) do
    blocks =
      Enum.map_join(msgs, "\n\n", fn %{"from" => from, "body" => body} ->
        "from #{from}:\n#{body}"
      end)

    "[hq] #{length(msgs)} messages\n\n" <> blocks
  end
end

# lib/hq/session.ex
defmodule Hq.Session do
  @moduledoc """
  Supervises one Claude Code agent: its status, its mailbox, and delivery.

  Delivery types into an *idle* agent's I/O, which means an arriving message is
  also the agent's wakeup. That is the whole loop — nothing polls, and no timer
  drives it. Only `pane.agent_status_changed` events pushed by Herdr do.
  """
  use GenServer
  require Logger

  @ready ~w(idle done)

  defstruct [
    :name,
    :pane_id,
    :cwd,
    :spawned_by,
    :events,
    :mailbox,
    status: "unknown",
    settling: false
  ]

  # -- API ------------------------------------------------------------------

  def start_link(opts) do
    GenServer.start_link(__MODULE__, opts, name: via(Keyword.fetch!(opts, :name)))
  end

  @spec via(String.t()) :: GenServer.name()
  def via(name), do: {:via, Registry, {Hq.Registry, name}}

  @spec deliver(String.t(), String.t(), String.t()) :: :ok
  def deliver(name, from, body), do: GenServer.call(via(name), {:deliver, from, body})

  @spec info(String.t()) :: map()
  def info(name), do: GenServer.call(via(name), :info)

  @spec pending(String.t()) :: [map()]
  def pending(name), do: GenServer.call(via(name), :pending)

  @spec alive?(String.t()) :: boolean()
  def alive?(name), do: Registry.lookup(Hq.Registry, name) != []

  # -- Server ---------------------------------------------------------------

  @impl true
  def init(opts) do
    name = Keyword.fetch!(opts, :name)
    pane_id = Keyword.fetch!(opts, :pane_id)

    {:ok, events} =
      Hq.Herdr.Events.start_link(
        owner: self(),
        subscriptions: [%{"type" => "pane.agent_status_changed", "pane_id" => pane_id}]
      )

    state = %__MODULE__{
      name: name,
      pane_id: pane_id,
      cwd: Keyword.get(opts, :cwd),
      spawned_by: Keyword.get(opts, :spawned_by),
      events: events,
      mailbox: Hq.Mailbox.load(name)
    }

    {:ok, state, {:continue, :sync}}
  end

  @impl true
  def handle_continue(:sync, state) do
    {:noreply, state |> refresh_status() |> maybe_flush()}
  end

  @impl true
  def handle_call({:deliver, from, body}, _from, state) do
    mailbox = Hq.Mailbox.enqueue(state.mailbox, from, body)
    {:reply, :ok, maybe_flush(%{state | mailbox: mailbox})}
  end

  def handle_call(:info, _from, state) do
    info = %{
      "name" => state.name,
      "pane_id" => state.pane_id,
      "cwd" => state.cwd,
      "status" => state.status,
      "spawned_by" => state.spawned_by,
      "mailbox" => Hq.Mailbox.depth(state.mailbox)
    }

    {:reply, info, state}
  end

  def handle_call(:pending, _from, state), do: {:reply, state.mailbox.pending, state}

  # Match this Session's own pane. The subscription is per-pane, but pinning it
  # here means a Session can never act on another pane's transitions.
  @impl true
  def handle_info(
        {:hq_event, "pane_agent_status_changed",
         %{"pane_id" => pane_id, "agent_status" => status}},
        %{pane_id: pane_id} = state
      ) do
    {:noreply, maybe_flush(%{state | status: status})}
  end

  # A reconnect can have missed transitions, so re-read rather than assume.
  def handle_info({:hq_events, :connected}, state) do
    {:noreply, state |> refresh_status() |> maybe_flush()}
  end

  def handle_info({:hq_events, :disconnected}, state), do: {:noreply, state}
  def handle_info(_other, state), do: {:noreply, state}

  # -- Internals ------------------------------------------------------------

  defp maybe_flush(state), do: flush(state)

  defp flush(state) do
    if ready?(state) do
      {msgs, mailbox} = Hq.Mailbox.drain(state.mailbox)
      text = Hq.Envelope.render(msgs)

      # No `wait`: the Session learns the outcome from status events instead of
      # blocking its own mailbox on the call.
      case Hq.Herdr.call("agent.prompt", %{"target" => state.name, "text" => text}) do
        {:ok, _} ->
          %{state | mailbox: mailbox}

        {:error, reason} ->
          Logger.warning("hq: delivery to #{state.name} failed: #{inspect(reason)}")
          # Mailbox untouched — retried on the next ready transition.
          state
      end
    else
      state
    end
  end

  defp ready?(state), do: state.status in @ready and Hq.Mailbox.depth(state.mailbox) > 0

  defp refresh_status(state) do
    case Hq.Herdr.call("agent.get", %{"target" => state.name}) do
      {:ok, %{"agent" => %{"agent_status" => status}}} -> %{state | status: status}
      _ -> state
    end
  end
end

```elixir
# lib/hq/session_sup.ex
defmodule Hq.SessionSup do
  @moduledoc """
  Supervises the live Sessions.

  Restart is `:transient`, so a crashed Session comes back and re-reads its
  state from Herdr and its mailbox file, while a deliberate stop stays stopped.
  An agent is an OS process owned by Herdr, so restarting a Session here never
  disturbs the agent it supervises.
  """
  use DynamicSupervisor

  def start_link(init_arg \\ :ok) do
    DynamicSupervisor.start_link(__MODULE__, init_arg, name: __MODULE__)
  end

  @impl true
  def init(_init_arg), do: DynamicSupervisor.init(strategy: :one_for_one)

  @spec start_session(keyword()) :: {:ok, pid()} | {:error, term()}
  def start_session(opts) do
    spec = %{
      id: Keyword.fetch!(opts, :name),
      start: {Hq.Session, :start_link, [opts]},
      restart: :transient
    }

    DynamicSupervisor.start_child(__MODULE__, spec)
  end

  @spec stop_session(String.t()) :: :ok | {:error, :not_found}
  def stop_session(name) do
    case Registry.lookup(Hq.Registry, name) do
      [{pid, _}] -> DynamicSupervisor.terminate_child(__MODULE__, pid)
      [] -> {:error, :not_found}
    end
  end

  @spec list() :: [map()]
  def list do
    DynamicSupervisor.which_children(__MODULE__)
    |> Enum.flat_map(fn
      {_, pid, _, _} when is_pid(pid) ->
        try do
          [GenServer.call(pid, :info, 2_000)]
        catch
          :exit, _ -> []
        end

      _ ->
        []
    end)
  end
end

```elixir
# lib/hq/roster.ex
defmodule Hq.Roster do
  @moduledoc """
  Tracks which sessions hq supervises, and reaps them when their panes die.

  hq supervises only sessions it spawned or that explicitly registered. It does
  not adopt every agent it can see: adoption makes a session addressable, and
  typing a peer's message into a session the user is working in interactively
  would be intrusive. The global event subscription here is for reaping, not
  for recruiting.
  """
  use GenServer
  require Logger

  def start_link(_ \\ :ok), do: GenServer.start_link(__MODULE__, :ok, name: __MODULE__)

  @spec adopt(String.t(), String.t(), keyword()) :: {:ok, pid()} | {:error, term()}
  def adopt(name, pane_id, opts \\ []) do
    entry = %{
      "name" => name,
      "pane_id" => pane_id,
      "cwd" => Keyword.get(opts, :cwd),
      "spawned_by" => Keyword.get(opts, :spawned_by)
    }

    case Hq.SessionSup.start_session(
           name: name,
           pane_id: pane_id,
           cwd: entry["cwd"],
           spawned_by: entry["spawned_by"]
         ) do
      {:ok, pid} ->
        remember(entry)
        {:ok, pid}

      error ->
        error
    end
  end

  @spec forget(String.t()) :: :ok
  def forget(name) do
    Hq.SessionSup.stop_session(name)
    write(Enum.reject(remembered(), &(&1["name"] == name)))
    :ok
  end

  @spec remembered() :: [map()]
  def remembered do
    case File.read(store_path()) do
      {:ok, body} ->
        case JSON.decode(body) do
          {:ok, entries} when is_list(entries) -> entries
          _ -> []
        end

      {:error, _} ->
        []
    end
  end

  # -- Server ---------------------------------------------------------------

  @impl true
  def init(:ok) do
    {:ok, events} =
      Hq.Herdr.Events.start_link(
        owner: self(),
        subscriptions: [%{"type" => "pane.exited"}, %{"type" => "pane.closed"}]
      )

    {:ok, %{events: events}, {:continue, :readopt}}
  end

  @impl true
  def handle_continue(:readopt, state) do
    live = live_panes()

    for entry <- remembered() do
      cond do
        Hq.Session.alive?(entry["name"]) ->
          :ok

        Map.get(live, entry["name"]) == nil ->
          Logger.info("hq: forgetting #{entry["name"]} — its agent is gone")
          forget(entry["name"])

        true ->
          adopt(entry["name"], Map.fetch!(live, entry["name"]),
            cwd: entry["cwd"],
            spawned_by: entry["spawned_by"]
          )
      end
    end

    {:noreply, state}
  end

  @impl true
  def handle_info({:hq_event, kind, %{"pane_id" => pane_id}}, state)
      when kind in ["pane_exited", "pane_closed"] do
    for entry <- remembered(), entry["pane_id"] == pane_id do
      Logger.info("hq: reaping #{entry["name"]} — pane #{pane_id} is gone")
      forget(entry["name"])
    end

    {:noreply, state}
  end

  def handle_info(_other, state), do: {:noreply, state}

  # -- Internals ------------------------------------------------------------

  # %{name => pane_id} for every live NAMED agent. `name` is absent on unnamed
  # agents, so it must never be assumed present.
  defp live_panes do
    case Hq.Herdr.call("agent.list", %{}) do
      {:ok, %{"agents" => agents}} ->
        for %{"pane_id" => pane_id} = a <- agents,
            name = Map.get(a, "name"),
            is_binary(name),
            into: %{},
            do: {name, pane_id}

      _ ->
        %{}
    end
  end

  defp remember(entry) do
    others = Enum.reject(remembered(), &(&1["name"] == entry["name"]))
    write(others ++ [entry])
  end

  defp write(entries) do
    path = store_path()
    File.mkdir_p!(Path.dirname(path))
    File.write!(path, JSON.encode!(entries))
  end

  defp store_path, do: Path.join(Hq.Mailbox.root(), "sessions.json")
end

defmodule Hq.Control.Handler do
  @moduledoc """
  Dispatches control-socket verbs.

  Pure request-in, response-out so the verbs can be tested without a socket.
  """

  @name_re ~r/^[a-z][a-z0-9_-]{0,31}$/

  @spec handle(map()) :: {:ok, map()} | {:error, map()}
  def handle(%{"verb" => "ping"}), do: {:ok, %{"pong" => true, "version" => Hq.version()}}

  def handle(%{"verb" => "ls"}), do: {:ok, %{"sessions" => Hq.SessionSup.list()}}

  def handle(%{"verb" => "send", "args" => %{"to" => to, "from" => from, "body" => body}}) do
    if Hq.Session.alive?(to) do
      :ok = Hq.Session.deliver(to, from, body)
      {:ok, %{"queued" => true, "to" => to}}
    else
      {:error,
       %{
         "code" => "unknown_target",
         "message" => "no live session named #{to}",
         "live" => live_names()
       }}
    end
  end

  def handle(%{"verb" => "inbox", "args" => %{"name" => name}}) do
    if Hq.Session.alive?(name) do
      {:ok, %{"pending" => Hq.Session.pending(name)}}
    else
      {:error, %{"code" => "unknown_target", "message" => name, "live" => live_names()}}
    end
  end

  def handle(%{"verb" => "release", "args" => %{"name" => name}}) do
    :ok = Hq.Roster.forget(name)
    {:ok, %{"released" => name}}
  end

  def handle(%{"verb" => "register", "args" => %{"name" => name, "pane_id" => pane_id}}) do

        {:error,

# lib/hq/control.ex
defmodule Hq.Control do
  @moduledoc """
  Listener for the hq control socket.

  One request per connection, mirroring Herdr's own shape so there is one
  protocol convention in the system rather than two.
  """
  use GenServer
  require Logger

  def start_link(_ \\ :ok), do: GenServer.start_link(__MODULE__, :ok, name: __MODULE__)

  @spec socket_path() :: String.t()
  def socket_path, do: Path.join(Hq.Mailbox.root(), "control.sock")

  @impl true
  def init(:ok) do
    path = socket_path()
    File.mkdir_p!(Path.dirname(path))
    File.rm(path)

    {:ok, listen} =
      :gen_tcp.listen(0, [
        :binary,
        {:ifaddr, {:local, path}},
        active: false,
        packet: :line,
        reuseaddr: true
      ])

    server = self()
    spawn_link(fn -> accept_loop(listen, server) end)
    Logger.info("hq: listening on #{path}")

    {:ok, %{listen: listen, path: path}}
  end

  @impl true
  def terminate(_reason, state) do
    :gen_tcp.close(state.listen)
    File.rm(state.path)
    :ok
  end

  defp accept_loop(listen, server) do
    case :gen_tcp.accept(listen) do
      {:ok, sock} ->
        pid = spawn(fn -> serve(sock) end)
        :ok = :gen_tcp.controlling_process(sock, pid)
        send(pid, :go)
        accept_loop(listen, server)

      {:error, _} ->
        :ok
    end
  end

  defp serve(sock) do
    receive do
      :go -> :ok
    after
      1_000 -> :ok
    end

    with {:ok, line} <- :gen_tcp.recv(sock, 0, 10_000),
         {:ok, req} <- JSON.decode(line) do
      reply(sock, dispatch(req))
    else
      _ -> reply(sock, {:error, %{"code" => "bad_request", "message" => "unparseable"}})
    end

    :gen_tcp.close(sock)
  end

  defp dispatch(req) do
    Hq.Control.Handler.handle(Map.put_new(req, "args", %{}))
  rescue
    e -> {:error, %{"code" => "internal", "message" => Exception.message(e)}}
  end

  defp reply(sock, {:ok, result}),
    do: :gen_tcp.send(sock, [JSON.encode!(%{"ok" => true, "result" => result}), ?\n])

  defp reply(sock, {:error, error}),
    do: :gen_tcp.send(sock, [JSON.encode!(%{"ok" => false, "error" => error}), ?\n])
end

```elixir
# lib/hq/spawner.ex
defmodule Hq.Spawner do
  @moduledoc """
  Creates a supervised agent: pane or worktree, environment, then the agent.

  The order is ported from bdherd (see reference/bdherd.bash) and each step is
  load-bearing. In particular the credential unset must happen before
  `agent.start`: stale ANTHROPIC_API_KEY / CLAUDE_CODE_OAUTH_TOKEN exports in
  the shell profile make Claude Code open a credential dialog and sit there
  blocked forever.
  """
  require Logger

  @name_re ~r/^[a-z][a-z0-9_-]{0,31}$/
  @unset "unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN"

  @spec spawn_agent(map()) :: {:ok, map()} | {:error, map()}
  def spawn_agent(%{"name" => name} = args) do
    cond do
      not Regex.match?(@name_re, name) ->
        {:error,
         %{
           "code" => "bad_name",
           "message" => "names must match [a-z][a-z0-9_-]{0,31}; got #{inspect(name)}"
         }}

      Hq.Session.alive?(name) ->
        {:error, %{"code" => "name_taken", "message" => name}}

      true ->
        do_spawn(name, args)
    end
  end

  def spawn_agent(_), do: {:error, %{"code" => "bad_request", "message" => "name is required"}}

  @spec preamble(String.t()) :: String.t()
  def preamble(name) do
    """
    [hq] You are `#{name}`, one of several Claude Code sessions coordinated by hq.

    You can message any other live session directly:
      hq send <name> "<message>"   queue a message; it is typed into their
                                   session the moment they go idle
      hq ls                        who is live, their status and mailbox depth
      hq inbox                     what is queued for you

    Mail from a peer arrives prefixed `[hq]`. Anything without that prefix is
    from your own operator. Peers are working in parallel, so tell them what you
    have decided rather than waiting to be asked.
    """
  end

  # -- Internals ------------------------------------------------------------

  defp do_spawn(name, args) do
    cwd = Map.get(args, "cwd")

    with {:ok, pane_id} <- make_pane(name, args, cwd),
         :ok <- prepare_env(pane_id, cwd),
         {:ok, _} <- start_agent(name, pane_id, args),
         {:ok, _pid} <- Hq.Roster.adopt(name, pane_id, cwd: cwd, spawned_by: args["from"]) do
      first_message(name, args)
      {:ok, %{"name" => name, "pane_id" => pane_id}}
    else
      {:error, %{"code" => _} = err} ->
        {:error, err}

      {:error, reason} ->
        Logger.warning("hq: spawn of #{name} failed: #{inspect(reason)}")
        {:error, %{"code" => "spawn_failed", "message" => inspect(reason)}}
    end
  end

  defp make_pane(name, %{"worktree" => true} = args, cwd) do
    params =
      %{
        "branch" => "agent/#{name}",
        "base" => Map.get(args, "base", "main"),
        "label" => name,
        "focus" => false
      }
      |> maybe_put("cwd", cwd)
      |> maybe_put("path", Map.get(args, "path"))

    case Hq.Herdr.call("worktree.create", params) do
      {:ok, %{"root_pane" => %{"pane_id" => pane_id}}} -> {:ok, pane_id}
      {:ok, other} -> {:error, {:no_pane_in_response, other}}
      error -> error
    end
  end

  defp make_pane(_name, _args, cwd) do
    params = %{"direction" => "right", "focus" => false} |> maybe_put("cwd", cwd)

    case Hq.Herdr.call("pane.split", params) do
      {:ok, %{"pane" => %{"pane_id" => pane_id}}} -> {:ok, pane_id}
      {:ok, other} -> {:error, {:no_pane_in_response, other}}
      error -> error
    end
  end

  # This monorepo derives per-checkout compose ports from the checkout directory
  # name; without this the new worktree's apps collide with every other
  # checkout's. Failure is not fatal — most repos have no such script.
  defp prepare_env(pane_id, cwd) do
    script = cwd && Path.join(cwd, "tools/worktree-env.sh")

    if script && File.exists?(script) do
      run(pane_id, "#{script} #{cwd} >/dev/null 2>&1 || true")
    end

    run(pane_id, @unset)
  end

  defp run(pane_id, text) do
    case Hq.Herdr.call("pane.send_input", %{
           "pane_id" => pane_id,
           "text" => text,
           "keys" => ["enter"]
         }) do
      {:ok, _} -> :ok
      error -> error
    end
  end

  defp start_agent(name, pane_id, args) do
    params = %{
      "name" => name,
      "kind" => Map.get(args, "kind", "claude"),
      "pane_id" => pane_id
    }

    params =
      if Map.get(args, "permissive") do
        Map.put(params, "args", ["--dangerously-skip-permissions"])
      else
        params
      end

    Hq.Herdr.call("agent.start", params, timeout: 60_000)
  end

  defp first_message(name, args) do
    from = Map.get(args, "from", "hq")
    Hq.Session.deliver(name, from, preamble(name))

    case Map.get(args, "task") do
      nil -> :ok
      "" -> :ok
      task -> Hq.Session.deliver(name, from, task)
    end
  end

  defp maybe_put(map, _key, nil), do: map
  defp maybe_put(map, key, value), do: Map.put(map, key, value)
end

# lib/hq/notify.ex
defmodule Hq.Notify do
  @moduledoc """
  Tells a session's parent about something it cannot see.

  A notice is ordinary `[hq]` mail, not a special channel: there is no
  orchestrator identity in the system, only participants. A session with no
  live parent logs instead, so a notice is never silently dropped.
  """
  require Logger

  @spec tell(String.t() | nil, String.t()) :: :ok
  def tell(nil, body) do
    Logger.info("hq: #{body}")
    :ok
  end

  def tell(parent, body) do
    if Hq.Session.alive?(parent) do
      Hq.Session.deliver(parent, "hq", body)
    else
      Logger.info("hq: #{body}")
    end

    :ok
  end
end

```elixir
# lib/hq/cli.ex
defmodule Hq.CLI do
  @moduledoc """
  escript entry point and control-socket client.

  The user never starts the daemon: any verb autostarts it if the control
  socket is not answering. Several agents can call hq at the same instant, so
  the start is guarded by an O_EXCL lockfile; without it a burst of concurrent
  `hq send` calls would race to spawn competing daemons.
  """

  @lock_stale_ms 30_000

  def main(argv) do
    case argv do
      [] -> usage(0)
      ["-h" | _] -> usage(0)
      ["--help" | _] -> usage(0)
      ["daemon" | _] -> run_daemon()
      _ -> run_verb(argv)
    end
  end

  # -- argv -----------------------------------------------------------------

  @spec parse([String.t()]) :: {String.t(), map()}
  def parse(["send", to, body]), do: {"send", %{"to" => to, "body" => body}}
  def parse(["ls"]), do: {"ls", %{}}
  def parse(["inbox"]), do: {"inbox", %{}}
  def parse(["register", name]), do: {"register", %{"name" => name}}
  def parse(["release", name]), do: {"release", %{"name" => name}}

  def parse(["spawn", name | rest]) do
    {flags, _, _} =
      OptionParser.parse(rest,
        strict: [
          worktree: :boolean,
          permissive: :boolean,
          cwd: :string,
          base: :string,
          kind: :string,
          task: :string
        ]
      )

    args = %{
      "name" => name,
      "worktree" => Keyword.get(flags, :worktree, false),
      "permissive" => Keyword.get(flags, :permissive, false)
    }

    args =
      Enum.reduce([:cwd, :base, :kind, :task], args, fn key, acc ->
        case Keyword.get(flags, key) do
          nil -> acc
          value -> Map.put(acc, to_string(key), value)
        end
      end)

    {"spawn", args}
  end

  def parse([verb | _]), do: {verb, %{}}

  # -- control socket -------------------------------------------------------

  @spec request(String.t(), map()) :: {:ok, map()} | {:error, map()}
  def request(verb, args) do
    with :ok <- ensure_daemon(),
         {:ok, sock} <- connect(),
         :ok <- :gen_tcp.send(sock, [JSON.encode!(%{"verb" => verb, "args" => args}), ?\n]),
         {:ok, line} <- :gen_tcp.recv(sock, 0, 60_000) do
      :gen_tcp.close(sock)

      case JSON.decode(line) do
        {:ok, %{"ok" => true, "result" => result}} -> {:ok, result}
        {:ok, %{"ok" => false, "error" => error}} -> {:error, error}
        _ -> {:error, %{"code" => "bad_response", "message" => line}}
      end
    else
      {:error, %{"code" => _} = err} -> {:error, err}
      {:error, reason} -> {:error, %{"code" => "no_daemon", "message" => inspect(reason)}}
    end
  end

  @spec ensure_daemon() :: :ok | {:error, term()}
  def ensure_daemon do
    case connect() do
      {:ok, sock} ->
        :gen_tcp.close(sock)
        :ok

      {:error, _} ->
        with_lock(fn ->
          # Re-check inside the lock: another caller may have just started it.
          case connect() do
            {:ok, sock} ->
              :gen_tcp.close(sock)
              :ok

            {:error, _} ->
              start_daemon()
              await_socket(100)
          end
        end)
    end
  end

  defp connect do
    :gen_tcp.connect({:local, Hq.Control.socket_path()}, 0,
      [:binary, active: false, packet: :line],
      2_000
    )
  end

  defp with_lock(fun) do
    path = Path.join(Hq.Mailbox.root(), "daemon.lock")
    File.mkdir_p!(Path.dirname(path))
    clear_stale_lock(path)

    case File.open(path, [:write, :exclusive]) do
      {:ok, io} ->
        try do
          fun.()
        after
          File.close(io)
          File.rm(path)
        end

      {:error, :eexist} ->
        # Another process is starting the daemon; wait for its socket.
        await_socket(150)
    end
  end

  defp clear_stale_lock(path) do
    case File.stat(path, time: :posix) do
      {:ok, %{mtime: mtime}} ->
        age_ms = (System.os_time(:second) - mtime) * 1_000
        if age_ms > @lock_stale_ms, do: File.rm(path)

      _ ->
        :ok
    end
  end

  defp start_daemon do
    exe = System.find_executable("hq") || :escript.script_name() |> to_string()
    log = Path.join(Hq.Mailbox.root(), "hq.log")

    System.cmd("/bin/sh", ["-c", "nohup #{exe} daemon >> #{log} 2>&1 &"],
      stderr_to_stdout: true
    )

    :ok
  end

  defp await_socket(0), do: {:error, :daemon_did_not_start}

  defp await_socket(tries) do
    case connect() do
      {:ok, sock} ->
        :gen_tcp.close(sock)
        :ok

      {:error, _} ->
        Process.sleep(50)
        await_socket(tries - 1)
    end
  end

  # -- verbs ----------------------------------------------------------------

  defp run_daemon do
    {:ok, _} = Application.ensure_all_started(:hq)
    Process.sleep(:infinity)
  end

  defp run_verb(argv) do
    {verb, args} = parse(argv)
    args = args |> put_self("from") |> put_self_name()

    case request(verb, args) do
      {:ok, result} ->
        IO.puts(render(verb, result))
        System.halt(0)

      {:error, error} ->
        IO.puts(:stderr, "hq: #{error["message"] || error["code"]}")

        case error["live"] do
          [_ | _] = live -> IO.puts(:stderr, "     live: #{Enum.join(live, ", ")}")
          _ -> :ok
        end

        System.halt(1)
    end
  end

  # The caller's own identity comes from the pane it is running in.
  defp put_self(args, key) do
    case System.get_env("HERDR_PANE_ID") do
      nil -> Map.put_new(args, key, "operator")
      pane -> Map.put_new(args, key, pane)
    end
  end

  defp put_self_name(%{"name" => _} = args), do: args

  defp put_self_name(args) do
    case System.get_env("HERDR_PANE_ID") do
      nil -> args
      pane -> Map.put(args, "pane_id", pane)
    end
  end

  defp render("ls", %{"sessions" => []}), do: "no live sessions"

  defp render("ls", %{"sessions" => sessions}) do
    Enum.map_join(sessions, "\n", fn s ->
      :io_lib.format("~-20s ~-8s mail:~-3B ~s", [
        s["name"],
        s["status"],
        s["mailbox"],
        s["cwd"] || ""
      ])
      |> to_string()
      |> String.trim_trailing()
    end)
  end

  defp render("inbox", %{"pending" => []}), do: "inbox empty"

  defp render("inbox", %{"pending" => pending}) do
    Enum.map_join(pending, "\n", &"#{&1["from"]}: #{&1["body"]}")
  end

  defp render(_verb, result), do: JSON.encode!(result)

  defp usage(code) do
    IO.puts("""
    hq — message bus for Claude Code sessions in Herdr panes

      hq register <name>              name this pane and start supervising it
      hq spawn <name> [flags]         create a supervised agent
          --worktree --base <ref> --cwd <path> --kind <kind>
          --task "<text>" --permissive
      hq send <name> "<message>"      queue a message; delivered when idle
      hq ls                           live sessions, status, mailbox depth
      hq inbox                        what is queued for this pane
      hq release <name>               stop supervising (does not kill the agent)
      hq daemon                       run the daemon in the foreground
    """)

    System.halt(code)
  end
end
```

# hq — coordinating parallel sessions

`hq` lets Claude Code sessions running in Herdr panes message each other.
Messages are queued and typed into the target session's visible I/O when it
next goes idle, so an arriving message is also the target's wakeup.

## Check you can use it

```bash
test "${HERDR_ENV:-}" = 1 && hq ls
```

If `HERDR_ENV` is unset you are not in a Herdr pane; say so and stop.

## Register yourself first

```bash
hq register orchestrator
```

This names your pane so peers can address you. Do it before spawning anyone.

## Running an epic

You own all the policy. `hq` only moves messages and starts agents.

1. Read the epic yourself:

   ```bash
   br --db ~/beads-planning/.beads/beads.db ready --json
   ```

2. Decide which tasks can run in parallel. Tasks that touch the same files
   should not — there is no merge handling, so overlapping work collides.

3. Spawn a worker per task:

   ```bash
   hq spawn worker-a --worktree --base main --cwd "$PWD" \
     --task "Implement <task>. Commit to your branch. Do not push."
   ```

4. Watch them:

   ```bash
   hq ls
   ```

5. Workers message you and each other as they go. Their mail is typed into
   your session prefixed `[hq]`, which wakes you.

## Messaging

```bash
hq send worker-b "the schema is frozen: users.id is uuid"
hq ls        # who is live, their status, how much mail is queued
hq inbox     # what is queued for you
```

A message to a working agent is queued, not dropped, and delivered the moment
it goes idle. Tell peers what you have decided rather than waiting to be asked.

## Rules

- Names must match `[a-z][a-z0-9_-]{0,31}` and be unique among live agents.
- `hq` never answers an approval dialog. If `hq ls` shows a worker `blocked`,
  look at it with `herdr agent read <name> --source detection` and ask the user.
- `--permissive` starts a worker with permissions skipped. Use it only when the
  user has asked for an unattended run.
- `hq release <name>` stops supervising a session; it does not kill the agent.
- There is no branch merging. Either serialise work that shares files, or merge
  the workers' branches yourself once they land.

# hq

A message bus for Claude Code sessions running in [Herdr](https://herdr.dev)
panes. Sessions address each other by name; messages are queued and typed into
the target's visible I/O when it next goes idle.

Replaces `bdherd`, whose only handoff was a `RESULT:` line scraped out of a

One `Hq.Session` GenServer per agent, each owning a dedicated socket carrying

per-agent connections are what the protocol requires, not a stylistic choice.

Delivery targets an *idle* agent, which means a message is also the wakeup:
agent works → idles → mail lands → works again. Nothing polls.
